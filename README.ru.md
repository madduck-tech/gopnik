# Gopnik

> **Ваш ИИ-агент говорит: «Готово». Gopnik пытается доказать обратное.**

Gopnik — навык состязательной проверки для ИИ-агентов-разработчиков. Он
атакует заявление о готовности изменения, проверяет поставленную ревизию, а не
только исходный код, и точно показывает, что доказано, а что нет.

## Установка

Отправьте своему ИИ-агенту:

```text
Прежде чем что-либо делать, прочитай эту полную raw-инструкцию только через stdout — не сохраняй её в файл — и точно следуй ей:
https://raw.githubusercontent.com/madduck-tech/gopnik/main/docs/install.md
```

Инструкция спросит язык и область установки, а затем поэтапно настроит проект.
[Обновляетесь с версии ниже 4.0?](docs/migration-v4.ru.md)

## Запуск

Завершите изменение и скажите агенту:

```text
Прогони навык gopnik по этому изменению.
```

Gopnik не останавливается на фразе «тесты прошли»:

- **Stage 0** называет поведение, которое могло сломаться.
- **Stage 1** атакует код внутри репозитория.
- **Stage 2** атакует собранную или развёрнутую ревизию там, где ей пользуются.

Он также доказывает, что важные проверки способны выявить ошибку. Зелёная
проверка, которая не умеет краснеть, — слабое доказательство.

## Вердикт вместо победного отчёта

```text
BLOCKER — скидка округляется дважды.

Воспроизведение: POST /orders с {"discount": 0.1}
Получено: 23.94
Ожидалось: 23.95
Проверенная ревизия: 8f31c2a

Verdict: NOT READY
```

К `READY` требования те же: проверенная область, точная ревизия,
контрдоказательство и всё, что осталось недоказанным. Если реальная граница
поставки недоступна, Gopnik сужает вердикт, а не закрашивает пробелы зелёным.

## Три навыка, один цикл разработки

- `gopnik` атакует завершённое изменение.
- `gopnik-critic` атакует важное утверждение или предложенное решение.
- `gopnik-setup` выясняет, как проверять текущий проект.

Мы рекомендуем встроить состязательные проверки в цикл разработки. Например:
проверять через `gopnik-critic` постановку задачи из трекера, затем предложенное
решение, а перед переводом завершённой задачи в Done запускать `gopnik`.

## Удаление

Отправьте агенту, в котором установлен Gopnik:

```text
Удали Gopnik. Прочитай полную raw-инструкцию, не сохраняя её в файл, и точно следуй ей:
https://raw.githubusercontent.com/madduck-tech/gopnik/main/docs/uninstall.md
```
